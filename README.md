# Scratch Klon

**A Scratch-inspired visual programming environment for kids, with a Swedish-language interface.** Kids learn programming concepts by dragging and connecting blocks.

## Features

- Visual block-based programming
- Swedish-language interface
- Game sharing and community features
- Like and comment system
- Multiple block types: movement, speech, loops, rotation

## Status

Complete — built as an educational tool to teach kids the basics of programming.
